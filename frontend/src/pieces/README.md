# Piece artwork

The twelve SVGs here are the **Cburnett** chess set from Wikimedia Commons, by
[Cburnett](https://commons.wikimedia.org/wiki/User:Cburnett), licensed
**CC BY-SA 3.0** (https://creativecommons.org/licenses/by-sa/3.0/). Unmodified.

Files: `w`/`b` (side) + `K Q R B N P`. Source pages: `File:Chess_{k,q,r,b,n,p}{l,d}t45.svg`
(`l` = white, `d` = black). Credited in the app footer as well.

They are kept separate from the application code on purpose: ShareAlike applies to these images
(and any edit of them), not to the code that displays them.
